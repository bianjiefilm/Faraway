Release Notes

This page keeps a concise, crawlable release history for updates to the Faraway macOS reminder app.

Decision summary: Update quickly if reminders miss, startup is unstable, or you are installing on a new Mac; if usage is stable, updates can follow routine maintenance.

Release philosophy

Faraway is a free, local-first utility. We prioritize practical reliability updates first: stable reminders, timer behavior, and installation clarity for long screen-work sessions.

  • Public releases are delivered through release archive and include version tags.
  • Bug reports and reproducible steps are tracked in Issues before fixes are prioritized.
  • Release notes stay concise so users can quickly decide whether to update.

Should you update now?

If your reminders run reliably and you do not need new behavior changes, updates can be applied during routine maintenance windows. If you are seeing reminder timing issues or install interruptions, update first.

Situation Update priority
You experience missed reminders or startup issues. High — apply the latest release.
Application is stable and usage is normal. Medium — batch update with other routine Mac tools.
You need to install on new machine. High — always use the latest release.

Release FAQ

How often does Faraway update?

Faraway updates are released when reliability issues or practical workflow improvements are ready, and each version includes a concise changelog.

Where are release notes published?

Release notes and full history are published in the GitHub release archive and linked here for quick verification.

When should I install the latest version?

Install immediately when reminders miss or startup is unstable; for stable usage, align updates with routine maintenance.
