What Faraway does in one minute

Faraway is a lightweight macOS menu bar utility that prompts you to pause every 20 minutes and look away for about 20 seconds. It is built for long focus sessions where eye fatigue and screen strain are common.

The value is simple: predictable breaks reduce cumulative strain, help maintain visual comfort, and support sustainable deep-work habits.

Core features

Built for real work sessions, Faraway focuses on reminders that help you create consistent rest habits.

Smart reminders

Full-screen reminder windows with a 20-second countdown appear only when needed and then disappear.

App-aware scheduling

Monitor all apps or only selected apps so breaks happen during intense workflows.

Custom intervals

Set the break rhythm that matches your workload, focus block, and task complexity.

Visible progress

Track daily completed breaks, streaks, and milestones to keep your eye-care habit visible.

How it works

  1. Install Faraway and allow it to run in the menu bar.
  2. Choose your preferred monitoring mode and break interval.
  3. Work with less worry; you will receive clear, full-screen reminders.
  4. Keep focus while reducing strain by completing a 20-second pause.

Why this matters

Extended screen sessions can increase eye fatigue and lower productivity. The 20-20-20 method is a practical habit that helps many users recover focus and comfort.

Who Faraway is for

  • Teams that want a lightweight, local-first pattern for eye-rest behavior.

Download and setup

Faraway supports macOS 13 or later. The release package includes everything needed to run locally.

  • 1) Go to GitHub Releases.
  • 2) Download the latest .dmg installer.
  • 3) Open the DMG and drag Faraway.app to Applications.
  • 4) Launch Faraway from Applications or Finder and complete first-run setup.

Privacy and data policy

Faraway is intentionally local-first. App settings and local reminders are run on your Mac. The product does not collect analytics telemetry by design.

  • No remote user profile tracking is described in product documentation.
  • No personal content from reminders is uploaded to external servers.
  • Release artifacts and issue reports are public through the repository links below.

If you need support or need to report a reproducible issue, use GitHub Issues.

Frequently asked questions

Is my data uploaded to the cloud?

No. Faraway stores data locally on your Mac and does not collect analytics or telemetry.

Can I disable monitoring for some applications?

Yes. Choose "Selected Apps" mode and include only the apps you want reminders to track.

Can I start Faraway automatically at login?

Yes. It can be enabled from settings after first launch.

Where is the codebase?

All source code is available on the project repository at the source repo.

Do I get updates and changelog notes?

Yes. Release notes and updates are published in the GitHub Releases page and can be reviewed before you update.

Can I use Faraway for work and personal use?

Yes. The app is usable in focused work sessions and short breaks for everyday use; you can configure intervals to match your workflow.

Can a team adopt Faraway?

Yes. Faraway can be used in team environments since it runs locally, does not need user accounts, and stays focused on your macOS workflow.
