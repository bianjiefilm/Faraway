Support

Faraway is a free product designed for long screen sessions. Use this page to find setup, troubleshooting, and support steps.

Fast-start help

  1. Install from GitHub releases.
  2. Move Faraway.app to Applications.
  3. Open on macOS 13+ and enable menu bar mode.
  4. Adjust interval and app-aware mode in preferences.

Troubleshooting

If reminders are not triggering, check the following in order:

  • App has Accessibility permission and menu-bar visibility is enabled.
  • Reminder interval is not set to an unrealistic value.
  • Selected app monitoring is not restricting all working apps.
  • Try restarting Faraway and re-checking launch at login settings.

Report a bug

When reporting issues, include:

  • macOS version and device model
  • Faraway version
  • Repro steps and expected result
  • Whether app-aware monitoring is enabled

Create a report in GitHub Issues.
